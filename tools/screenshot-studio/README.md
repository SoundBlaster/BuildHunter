# Screenshot Studio

Open `index.html` in a modern browser to compose Mac App Store screenshots locally.
No server or installation is required. Images are processed on the device and are
not uploaded. The included preview windows contain fictional demonstration data;
replace them with screenshots of the actual app before exporting store images.

1. Pick a composition and drop or select one or two app screenshots.
2. Optionally add a desktop background and the app icon. If the desktop already
   includes a menu bar and Dock, turn off **Show menu bar and Dock**.
3. Edit the headline and cards, choose a color, resize the windows and drag them
   on the preview. Select an output size and export the PNG.

The built-in menu bar and Dock are decorative illustrations, not captures of
macOS. Window images retain their aspect ratio. The editor does not alter text
inside uploaded screenshots; prepare the app content before capturing it.

This standalone authoring tool is not shipped in BuildHunter and does not change
the app's scanning or distribution behavior.
