Write a scan template

A template is a JSON file that describes what to find. It does not run commands or delete files.

  1. Start with an example. Open Settings → Templates and choose New…. The example finds a forge-out directory beside a forge.project marker. To start from a file, choose Import JSON….
  2. Describe the artifact. Change the package and target titles. Keep the generated identifiers unique, or choose your own stable identifiers. The swift, rust and python namespaces are reserved.
  3. Set the matching conditions. Replace forge-out with the exact name to find, and forge.project with the marker name in its parent folder. The node.kind value is directory or regular_file. The marker is checked by name; its contents are not read.
  4. Check and save. Choose Check and fix any diagnostics. Choose Save As…, select where to keep the JSON, and enable the saved template in the list.
  5. Try a scan. Make a small test folder with a matching artifact and marker and a similar folder without the marker. Start a new scan or choose Rescan, and check that only the intended artifact appears.

Connected files remain where you put them, including in a Git repository. Enabled files are reloaded for each new scan. If an enabled template is broken or missing, fix or disable it before the next scan.

For every supported field and operator, see the template language reference.
