01 / See the whole picture

From clutter to clarity.

Порядок начинается с обзора.

Scan a folder for Swift, Rust and Python build outputs and caches. Explore an interactive diagram, sort findings by size and open them in Finder. BuildHunter reads files; it never deletes them.

Просканируйте папку и найдите артефакты и кэши Swift, Rust и Python. Изучайте интерактивную диаграмму, сортируйте результаты и открывайте их в Finder. BuildHunter только читает файлы и ничего не удаляет.

02 / For you and your agent

A good nose for the terminal, too.

Хорошее чутьё и в терминале.

The GitHub app includes a CLI with JSON output, ready for your scripts or coding agent. Make it your own with JSON templates in the app.

В GitHub-версии есть CLI с выводом JSON для скриптов и coding agents. Собственные JSON-шаблоны можно подключать в приложении.

/Applications/BuildHunter.app/Contents/MacOS/
build-hunter ~/Development --json

Custom templates are currently available in the app; CLI uses built-in rules.

Свои шаблоны пока доступны в приложении; CLI использует встроенные правила.
